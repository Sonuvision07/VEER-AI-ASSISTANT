# VEER visual identity

- App theme: dark minimal chat UI.
- Background: #101214
- Surface: #1A1D21
- Border: #2C3137
- Primary text: #F1F2F4
- Muted text: #A6ABB3
- Accent: #3DD6C4
- Accent foreground: #062B27
- Launcher mark: teal circle, muted teal ring, five deep-teal voice bars.
- Typography: bundled Inter variable font from Google Fonts; see `app/src/main/assets/Inter-OFL.txt`.
- 512px vector master: `app/src/main/assets/veer-icon-512.svg`.

The repository did not contain the requested supplied 1024x1024 PNG, so the textual fallback icon specification was implemented as vector resources.
